# Her Gün Yeni Bir Bilgi

Her gün otomatik olarak üretilen kısa, dikey "Top 10" bilgi videoları: Türkiye ve dünya hakkında merak uyandıran listeler, Türkçe seslendirme ve her gün farklı bir görsel temayla.

Videolar Python (Pillow + ffmpeg) ile üretilir, Piper ile seslendirilir ve GitHub Actions üzerinde çalışır. Konular `topics/` klasöründeki JSON dosyalarından gelir.

**Ses:** Piper "Fahrettin" Türkçe sesi (CC0 lisans, ticari kullanım serbest), GitHub Actions içinde çalışır.
